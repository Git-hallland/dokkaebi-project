# 소셜 로그인 브랜드 자산

확인일: 2026-09-01

- `google-g-logo.png`: [Google Sign in branding guidelines](https://developers.google.com/identity/branding-guidelines)에서 제공하는 공식 컬러 G 로고. 로그인 버튼 안에서만 원본 색상과 비율을 유지해 사용한다.
- `kakao-login.jpg`: [Kakao Developers 공식 로그인 튜토리얼](https://developers.kakao.com/docs/en/tutorial/login)에서 로그인 버튼 예제로 제공하는 Kakao CDN 자산. Kakao 로그인 동작에만 원본 비율을 유지해 사용한다.

두 자산은 각 제공자의 로그인 기능을 식별하는 용도로만 사용하며, 사이트 자체 브랜드처럼 사용하거나 형태·색상을 변형하지 않는다.
